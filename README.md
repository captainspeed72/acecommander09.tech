# acecommander09.tech

A modern personal website built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript (96%)
- **Styling:** Tailwind CSS, CSS (2.1%)
- **JavaScript:** 1.9%
- **UI Components:** Custom component library with shadcn/ui

## 📁 Project Structure

```
acecommander09.tech/
├── app/              # Next.js app directory
├── components/       # Reusable React components
├── hooks/           # Custom React hooks
├── lib/             # Utility functions and libraries
├── public/          # Static assets
├── styles/          # Global styles
├── components.json  # Component configuration
├── tailwind.config.js
├── tsconfig.json
└── next.config.mjs
```

## 🛠️ Installation

```bash
# Clone the repository
git clone https://github.com/captainspeed72/acecommander09.tech.git

# Navigate to the project directory
cd acecommander09.tech

# Install dependencies
npm install
```

## 🏃 Running the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🔨 Building for Production

```bash
# Create an optimized production build
npm run build

# Start the production server
npm start
```

## 📝 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint
